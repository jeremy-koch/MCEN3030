# Anscombe's Quartet (brief)

This is really interesting, and should impress upon you the importance of plotting your data and fits to check the validity!

[Anscombe's Quartet](https://en.wikipedia.org/wiki/Anscombe%27s_quartet)

- The first data set is very reasonably fit by a line, but it has some scatter (i.e. noise in the data).
- The second data set is clearly not linear, but has very little noise. (It could potentially still be fit by a linear model though, but that linear model would probably have an $\sim x^2$ term.)
- The third and fourth data sets have dramatic outliers.

All four data sets have the same mean, fit equation, and $R^2$!
